3. MODAL SHOWCASE SETUP (CURRENTLY ACTIVE)
===============================================================================

CURRENT CONFIGURATION:
- Component: SmartWelcomeOfferModal
- Location: app/layout.tsx (shows on every page)
- Delay: 2 seconds after page load
- Persistence: Shows again after 3 days if closed

HOW TO CHANGE THE OFFER TYPE:

Option 1: Welcome Offer (CURRENT)
   Replace in layout.tsx: <SmartWelcomeOfferModal />
   Best for: New visitor discounts

Option 2: Flash Sale
   Replace in layout.tsx: <SmartFlashSaleModal />
   Best for: Limited time offers, urgency

Option 3: Seasonal Campaign
   Replace in layout.tsx: <SmartSeasonalModal />
   Best for: Holiday packages, seasonal deals

Option 4: Newsletter Signup
   Replace in layout.tsx: <SmartNewsletterModal />
   Best for: Building email list

HOW TO CHANGE TIMING:
Edit the component props:
- showDelay={2000} → Change to showDelay={5000} for 5 seconds
- persistenceDays={3} → Change to persistenceDays={7} for 7 days

HOW TO DISABLE MODAL:
Remove or comment out this line in app/layout.tsx:
// <SmartWelcomeOfferModal />

5. CUSTOMIZATION GUIDE
===============================================================================

CHANGING OFFER CONTENT:

For Modal (Current Setup):
Edit the SmartWelcomeOfferModal component:
- title: Main headline
- subtitle: Small text above title
- description: Explanation text
- originalPrice: Crossed-out price
- salePrice: Current offer price
- urgencyText: "Limited time" messaging
- badgeText: "Welcome Offer", "Flash Sale", etc.
- ctaText: Button text

CHANGING IMAGES:
- Upload your image to /public/ folder
- Use path like "/my-offer-image.jpg"
- Recommended sizes:
  * Modal: 800x600px
  * Hero Banner: 1200x600px
  * Cards: 600x400px

CHANGING COLORS:
The components use your existing brand colors:
- Primary: Amber (#f59e0b) - change in tailwind.config.ts
- CTA buttons automatically use your amber theme
- Background gradients can be customized per component

CHANGING TIMING:
- showDelay: How long before modal appears (milliseconds)
- persistenceDays: How many days before showing again
- autoClose: Auto-close timer (0 = manual close only)

7. TROUBLESHOOTING
===============================================================================

MODAL NOT SHOWING:
1. Check browser localStorage - clear it to reset
2. Make sure component is imported in layout.tsx
3. Check console for JavaScript errors
4. Verify image URLs are correct

MODAL SHOWING TOO OFTEN:
1. Increase persistenceDays value
2. Change persistenceStrategy to "session" for testing
3. Clear localStorage to reset for testing

MODAL NOT RESPONSIVE:
1. Components are built mobile-first
2. Test on different screen sizes
3. Check for CSS conflicts with existing styles

IMAGES NOT LOADING:
1. Verify image is in /public/ folder
2. Use correct path format: "/image-name.jpg"
3. Check image file size (optimize for web)

STYLING CONFLICTS:
1. Components use Tailwind CSS (same as your site)
2. Use className prop to add custom styles
3. Check for CSS specificity issues
